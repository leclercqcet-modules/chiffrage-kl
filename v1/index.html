📖 Guide d'utilisation
Module Chiffrage KL

Le Module Chiffrage KL est un outil mobile dédié aux experts en assurance pour établir des chiffrages de dommages structurés par famille.

Il est organisé en 4 familles de chiffrage : Immobilier, Embellissements, Mobilier et Garanties Annexes. Chaque famille dispose de ses propres colonnes de calcul adaptées à sa nature.

Le chiffrage est sauvegardé automatiquement entre chaque saisie. Vous pouvez gérer plusieurs chiffrages simultanément depuis l'écran d'accueil.

💡 Commencez toujours par renseigner les Options générales avant d'ajouter des lignes de chiffrage — c'est obligatoire.

Avant toute saisie, vous devez définir 4 paramètres globaux :

  • Nature globale de règlement : Indemnité pécuniaire, Réparation en nature, Auto réparation, Pour information ou Mixte. En mode Mixte, chaque ligne sera à paramétrer individuellement.
  • Taux de TVA global : choisissez un taux fixe pour tout le chiffrage, "Pas de TVA" pour masquer toutes les colonnes TTC, ou "Mixte" pour gérer la TVA ligne par ligne.
  • Taux de vétusté appliqué : taux par défaut appliqué sur toutes les lignes, ou "Mixte" pour le définir individuellement.
  • Taux de vétusté contractuelle : taux maximum récupérable selon le contrat, avec le type (VAN à concurrence ou VD à partir de).
⚠️ En mode Mixte (nature ou TVA), une alerte bloquante s'affichera dans les Totaux si des lignes n'ont pas été paramétrées. La génération du récapitulatif sera impossible tant que toutes les lignes ne sont pas renseignées.

La ventilation est disponible pour les familles Immobilier et Embellissements. Elle permet de regrouper les lignes de chiffrage par pièce ou par zone, rendant le chiffrage plus lisible.

Comment l'activer : appuyez sur le bouton ⊞ Ventiler dans le bandeau de la famille. Si des lignes existent déjà avec un champ "Pièce / Ouvrage" renseigné, elles seront automatiquement regroupées par valeur identique.

Pour déplacer une ligne dans une autre sous-catégorie, modifiez le champ "Pièce" puis appuyez sur ✓ Valider la pièce et ventiler.

Le bouton 🔐 Sous-catégorie avec plafond apparaît lorsque la ventilation est active. Il permet d'ajouter un plafond de garantie par groupe de pièces. Le sous-total affiche alors l'indemnité plafonnée et le découvert éventuel.

💡 Pour pouvoir appliquer des plafonds par pièce, la ventilation doit impérativement être activée. Sans ventilation, seul le plafond global des Garanties Annexes est disponible.

Le bouton ⚖️ Convention IRSI (entre les options et les onglets) calcule automatiquement l'assiette IRSI et détermine si le dossier est éligible.

Calcul de l'assiette : total HT Immobilier + Embellissements + Frais annexes non immatériels + Mobilier vétusté déduite.

Seuils :

  • Tranche 1 : de 1 € à 1 600 € HT
  • Tranche 2 : de 1 601 € à 5 000 € HT
  • Au-delà de 5 000 € HT : Non éligible

Pour les Garanties Annexes, chaque ligne dispose d'un bouton ⚪ Non immatériel / 🔵 Immatériel. Les préjudices immatériels sont exclus de l'assiette IRSI mais affichés séparément en TTC.

💡 Le module IRSI se met à jour en temps réel dès que vous modifiez le chiffrage. Pensez à cocher les lignes immatérielles dans les Garanties Annexes avant de consulter l'éligibilité.

Le mode Pour information est disponible dans la nature globale de règlement et sur chaque ligne de chiffrage.

Lorsqu'une ligne est en mode "Pour information" :

  • Les montants de dommages (HT, TTC, vétusté) sont calculés normalement et apparaissent dans les tableaux
  • Les indemnités immédiate et différée sont forcées à 0 €
  • Dans le récapitulatif final, une ligne distincte "Dommages chiffrés pour information" affiche la somme TTC de ces postes, sous l'indemnité totale
💡 Ce mode est utile pour chiffrer des dommages connexes ou contestés sans les intégrer à l'indemnisation principale.

Le bouton 📋 BPU (à côté de la franchise) permet d'activer un Bordereau de Prix Unitaires pour accélérer la saisie.

Deux types de BPU sont disponibles :

  • BPU Personnalisé : votre propre bibliothèque de prix (à configurer dans les Options)
  • BPU Assureurs : COVEA, MAIF, ACM, SWISS LIFE, AXA

Une fois un BPU activé, un bouton 📋 Ajout BPU apparaît sur chaque ligne de chiffrage. En cliquant, la bibliothèque s'ouvre et la sélection d'un poste renseigne automatiquement la désignation, le prix unitaire et l'unité.

Vous pouvez changer de BPU en cours de saisie sans perdre les lignes déjà créées. Pour revenir à la saisie manuelle, cliquez sur "✕ Désactiver le BPU".

💡 Les bibliothèques BPU sont en cours de développement. L'infrastructure est en place et sera alimentée prochainement.

La fonctionnalité Définir des bénéficiaires permet d'associer chaque ligne de chiffrage à un ou plusieurs destinataires d'indemnité.

Elle s'active dans les Options générales de chiffrage. Elle se déclenche également automatiquement dès qu'une nature de règlement "Réparation en nature" est détectée (globalement ou sur une ligne).

Une fois activée :

  • Ajoutez les bénéficiaires via le bouton "＋ Ajouter un bénéficiaire" — en saisie manuelle ou depuis la liste pré-enregistrée (configurable dans ⚙️ Options)
  • Cochez le bouton REN à côté d'un bénéficiaire pour indiquer qu'il s'agit d'une Société de Réparation en Nature — son indemnité sera automatiquement basculée en intégralité en immédiate
  • Sur chaque ligne de chiffrage, une section "👤 Bénéficiaire(s) de l'indemnité" apparaît — cochez le ou les bénéficiaires concernés
  • Utilisez le filtre "Afficher uniquement pour :" pour n'afficher que les lignes d'un bénéficiaire spécifique

Dans le récapitulatif final, un tableau "Ventilation par bénéficiaire" résume les indemnités par destinataire.

⚠️ Pour un bénéficiaire REN : si un découvert de garantie est détecté (plafond ou vétusté non récupérable), une alerte s'affiche dans le récapitulatif signalant que le REN intégral n'est pas possible.

Le bouton ✉️ dans le bandeau génère un récapitulatif complet du chiffrage.

La génération est bloquée si :

  • Le mode nature Mixte comporte des lignes sans nature assignée
  • Le mode TVA Mixte comporte des lignes sans taux de TVA renseigné

Le récapitulatif contient :

  • Les métadonnées du dossier (référence, franchise, TVA, vétusté)
  • Un tableau détaillé par famille de chiffrage
  • Un tableau récapitulatif : Total HT/TTC, indemnités immédiate et différée, franchise, Indemnité Totale
  • Si applicable : les dommages "Pour information" en ligne séparée

Sur iPhone, le bouton ⬆ Partager ouvre directement le menu de partage iOS. Sur desktop, le document s'ouvre en vue imprimable.

💡 Le bouton ✅ dans le bandeau finalise et archive le chiffrage — il passe dans la section "Dossiers archivés" de l'accueil.
